# EGGARO — Custom 3D Map System

Sistema propio para reconstruir el diseño del mapa en 3D sin depender de un GLB único.

Incluye terreno procedural, río, camino, trigo, cueva, casas, aserradero, molino, pozo, manzano, vegetación, rocas y un editor para colocar/borrar piezas.

Abre `map-system/index.html` en GitHub Pages.
